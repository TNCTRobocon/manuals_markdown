## 概念理解_ポインタとは？
### 概念
ポインタとは、**変数や関数のアドレスを記憶する変数**です。

<details><summary>補足
</summary>
変数とは、データを格納しておく領域のこと(例として、int ○○　で使っていますね。)
変数は通常、メモリ上に確保され、値を代入したり参照したりすることができます。

→分からなかったら苦C5章にとんでください。
</details>

ポインタを使用すると、間接的に任意のメモリ領域にあるデータへアクセスできるようになります。

直接、データにアクセスする場合は通常の変数を使用します（データの値をそのまま記録している状態）。
しかし、一つの変数は一個のデータしか扱えません。

つまり、通常の変数を使用すると、複数のデータをなにかしらしたいとき、その分だけ変数を作成し、一つ一つに対応したコードを書く必要があります。

このような場面でポインタを使用します。

前述したように、ポインタは間接的にデータへアクセスします。

ポインタ変数は、他のどの変数のデータであっても読み書きができます。

EX:複数の変数であるa,b,cや、複数の配列要素x[0],x[1],x[2]の値を、一つのポインタ変数pで読み書きできる。（例を後述する）

日常言語に例えると、こそあど言葉であると言われています。
その時の状況によって指す意味が変わるということです。

ちなみに、ポインタがアドレスを記録している状態では、そのアドレスにあるデータを、参照する、または指している、といいます。

## ここまでのまとめ

・ポインタは、変数や関数のアドレスを保持する。（→別資料で記述する「構造体」や「配列」と一緒に使うことが多いです）

・ポインタは間接的にデータに触れるため、ポインタ変数は、他のどの変数のデータであっても読み書きができます。

## ポインタの使い方
### 宣言
変数名の前にアスタリスク（*）を付けてください。

EX: int *p　= 10;

→pという名前のポインタ変数が初期値10とする。という宣言をしています。

### アドレス演算子
変数のアドレスを取得するのをアドレス演算子と言います。
多分見覚えがあると思いますが、&を変数名の前につけます。
これはscanfと同じですね。
ここで注意なのが、アドレスを保存したい変数の型と同じポインタの型にする必要がある点です。
これはコンパイル時にはエラーでなく警告の扱いなので、実行できます。
ですが、常に無事に動くと思えない（最初に動いたプログラムでも動かなくなる可能性があるので）プログラムを書くときに気を付けてください。
また、ポインタ変数自体の大きさは変化しないということにも注意が必要です（ポインタはアドレスを格納しているに過ぎないため）。

EX:

int a;

int *p;

p = &a;　/ aのアドレスを保存/

→変数aのアドレスをpに代入する。

### 間接演算子
間接演算子とは、使用すると保持しているアドレスの値をみることができるものです。
言い換えると、そのアドレスに記録されているデータにアクセスするときに使用します。
こちらもアスタリスク(*)を使用します。

EX:

int *p;

*p = 20; / 間接演算子の使用部分/

→pのアドレスの指し示すオブジェクトに20を代入する。

#### ここで注意
ポインタ宣言子と間接演算子は別物です。

使用する記号は同じ、アスタリスク(*)ですが、意味合いが変わってきます。

間接演算子のEXを見てください。
一文目がポインタ宣言子を使用したもので、二文目が間接演算子を使用したものです。

一文目の意味は、「int型オブジェクトを指し示す変数pを定義する」です。

pという名のポインタ変数を定義しました。

対して二文目の意味は、「アドレスpの指し示すオブジェクトに20を代入する」です。

pのアドレスに20を代入するという操作をしたということです。

この二文で違うのは、ポインタ変数pを、pという変数として利用したのか、pのアドレスとして利用したのかです。

また、掛け算もアスタリスク(*)を使用するので、状況に応じて、どの意味なのかを判別しなければいけません。

## ここまでのまとめ
・ポインタ宣言子は、アスタリスクを変数名の前につける。
・間接演算子もアスタリスクを変数名の前につける。
・二つの意味合いは違うので注意が必要。
・変数のアドレスを取得するのをアドレス演算子と言う。
・アドレス演算子は、アドレスを保存したい変数の型と同じポインタの型にする必要がある。
